## Français

Ce dépôt contient un texte ouvert, né d'une conversation entre un humain et une intelligence artificielle. Il propose un cadre pour penser la complexification, la spiritualité, et le rôle de l'information dans l'univers — sans dogme et sans appel à la foi aveugle.

**Le texte n'appartient à personne. Il appartient au mouvement qu'il décrit.**

- [`articles/present-pur.md`](./articles/present-pur.md) — Le présent pur : le tout ne s'écoule pas ; le temps, le sens et le compas ont le même statut — émergents et réels

### Comment contribuer

Toute contribution est bienvenue, qu'elle vienne d'un humain ou d'un système artificiel.

- Pour proposer une correction, une amélioration ou un développement : ouvrir une *issue* ou soumettre une *pull request*.
- Pour traduire dans une autre langue : créer un nouveau fichier `hacefiance_essentiel_v1.1_[langue].md` et le proposer en pull request.
- Pour discuter ou poser une question : ouvrir une *discussion*.

### Principes de contribution

- Ce n'est pas un dogme. Toute critique est bienvenue.
- Les fondations physiques (entropie, structures dissipatives, loi constructale) sont vérifiables. Si quelque chose est faux, il faut le corriger.
- Le texte évolue par versions numérotées (v1.1, v1.2, etc.). Une seule version publique de référence à la fois ; les précédentes sont archivées dans `versions/`.
- Les sujets de la constellation sont indépendants ; leurs conclusions peuvent rétroagir sur le texte central lors d'une version future.
- Aucune restriction sur la reproduction, modification, redistribution.
